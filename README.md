### 微程序实现

指令字长16位，操作码5位，指令31组，共80条

除特殊运算，默认16位二进制数

#### 寻址方式

| 立即数 | 寄存器寻址 | 直接寻址 | 间接寻址 | PC相对寻址 | 基址寻址 | 变址寻址 |
| ------ | ---------- | -------- | -------- | ---------- | -------- | -------- |
| √      | √          | √        | √        | √          | √        | ×        |

没有变址寻址的原因是操作码不够了（其实可以继续扩展，不过比较麻烦）

#### 指令类型

| 数据传送 | 算术运算 | 位操作 | 串操作 | 控制转移 | 处理机控制 |
| -------- | -------- | ------ | ------ | -------- | ---------- |
| √        | √        | √      | ×      | √        | √          |
| 8条      | 8条      | 8条    | 0条    | 6条      | 1条        |

#### 指令名称

参考8086命名方式

数据传送：LOAD存数指令 STORE取数指令 MOV转移指令 XCHG交换指令 PUSH压栈指令 POP弹栈指令 LOADEX存数扩展指令 STOREEX取数扩展指令

算术运算：ADD加法指令 SUB减法指令 MUL乘法指令 DIV除法指令 INC自增指令 DEC自减指令 NEG取负指令 CMP比较指令

位操作：AND求与指令 OR求或指令 XOR异或指令 NOT取非指令 SHL逻辑左移指令 SAL算数左移指令 SHR逻辑右移指令 SAR算数右移指令

控制转移：JMP无条件跳转指令 JZ为零则跳转指令 JNZ非零则跳转指令 LOOP循环指令 CALL子程序调用指令 RET子程序返回指令

处理机控制：HLT停机指令

####  后继地址形成方式

顺序执行、无条件跳转、操作码跳转（根据操作码跳转到程序入口地址）、源跳转（根据源操作数的类型进行进一步的跳转，实现相同操作码执行不同的寻址方式）、目的跳转（同前一个）、转移跳转（为MOV操作特别设置）

####  微指令设计

地址共12位、微指令24位，详见微指令设计文件

ROM大小为4096\*24bits

####  程序设计

RAM大小65536\*12bits

共设计5个程序进行验证

1、递推计算斐波那契数列

2、递推计算阶乘

3、指令混合测试

4、基于全局变量传参的子程序递归计算阶乘

5、基于栈传参的子程序递归计算阶乘

详细见实验报告
